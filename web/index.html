Quick Start

Find cardsUse Card Search or open Search Options for detailed filters.
Add cardsRight-click a result or drag it into the deck.
Edit the deckDrag cards to reorder or move them between valid deck zones.
Save or shareSave YDK files, export supported formats, or copy deck text.

Search

  • Card Search performs free-text searching. Search Text in Search Scope mirrors the same value.
  • Use Card Pool, Card Type, Limit Status, Maximum Results, and the available sort controls to narrow results.
  • Context-specific filters appear only when applicable. Pendulum shows Scale controls, Link shows Link Rating and Arrow Directions with Link Materials, and Xyz provides Xyz Materials.
  • Effect Text is collapsible. Effect Characteristics includes Hand Trap, Activates from Hand, Special Summon from Hand, Self Cost from Hand, and Reveals from Hand.
  • Trap Monsters are searchable from both Monster Cards and Trap Cards.
  • Reset Search clears all search text and criteria.
  • Grid, Details, and List provide alternate result views. Card artwork and card name are always protected as identity information. The normal metadata priority is Attribute, Level/Rank, Type, Subtype, ATK, DEF, Link, then Scale. Metadata used by active search criteria receives higher visibility priority, and selecting a mechanic such as Link, Pendulum, Xyz, Synchro, or Ritual elevates that mechanic's defining Link, Scale, or Level/Rank information only for that search. Available width is used before lower-priority information is truncated or hidden. Search List column dividers can be dragged to resize columns or double-clicked to auto-fit them.

Deck Editing

  • Right-click a search result to add one copy to its normal deck zone. Repeat the add action for additional copies.
  • Ctrl + right-click adds or moves a card to or from the Side Deck where applicable.
  • Drag cards to reorder them or move them between valid deck zones.
  • Right-click a deck card or press Delete on a selection to remove it.
  • Ctrl + click toggles selection, Shift + click selects a range, and Alt + click duplicates.
  • Undo and Redo are available for normal deck editing.

Views & Card Details

  • Grid, List, Readable, and YDK deck views remain synchronized.
  • Click a card to inspect it in Card Details.
  • Card text can be selected and copied.
  • The YDK view displays numeric card codes required by the YDK format.

Deck Sort

  • Select the deck sections and card families you want to reorganize.
  • Choose a sort field and direction, then apply optional subtype criteria.
  • Loaded File Order restores the order captured when the deck was opened.
  • Last Manual Order restores the most recently captured manual arrangement for each selected deck zone.
  • When undocked, Dock only returns the panel to the layout. Pin docks and pins it.

Validation, Statistics & Opening Hand

  • Validation checks common deck-size, placement, and Forbidden List conditions.
  • Statistics summarizes the current deck composition.
  • Draw 5 samples five random Main Deck cards without changing the deck.

Files & Clipboard

  • Open and Save work with supported deck files.
  • Recent provides quick access to recently opened decks.
  • Import Clipboard accepts supported YDK, YDKE, and readable deck text.
  • Export and Copy commands provide supported interchange formats.
  • Keep backups of important deck files before extensive editing or conversion.

Card Database

  • Use Refresh Cards & Rules to retrieve current supported card information and card-pool data.
  • The database status shows the total cards loaded and, when available, the Rush Duel record count.
  • Open Application Data Folder opens the local application data location.
