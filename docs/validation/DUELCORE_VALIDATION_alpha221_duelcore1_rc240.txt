PRODUCT FIX

The outer launcher in rc239 has no Windows resource directory. RC240 links the original application icon into the launcher at compile time, restoring the embedded icon that Windows uses for the EXE and its desktop shortcut. The original artwork image bytes are preserved at 16, 24, 32, 48, 64, 128 and 256 pixels. No shortcut target or updater installation behavior is changed.

The resource object is generated with github.com/akavel/rsrc pinned to v0.10.2 and checked into source. Normal builds do not download a resource compiler. Only zero-plane ICO directory metadata is normalized to one plane, matching the original native baseline's group descriptors. The completed EXE is not modified to add its icon.
