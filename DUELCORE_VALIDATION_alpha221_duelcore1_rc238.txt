REPORTED FAILURE AND FIX

The owner supplied a screenshot from rc236 showing rc237 available but Download not clickable. The available state incorrectly received the is-progress CSS class, whose Download rule set pointer-events:none and reduced opacity. The earlier isolated updater browser test did not load this stylesheet and missed the mouse hit-target failure.

RC238 applies progress state only while checking or downloading. Available updates remain actionable. Dimmed Download styling now follows the actual disabled attribute. The timer and restart-guard browser test loads the actual application stylesheet.

A new regression tests normal mouse activation with both the full source stylesheet and the stylesheet extracted from the generated native core. It tests 823 and 1280 pixel viewport widths, the same available/cooldown-message combination shown in the screenshot, and verifies that Download generates exactly one service request without starting an installation.
